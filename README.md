# Frazer Pearce's homepage

Public website: https://frazerpearce.github.io/

A responsive, standalone static homepage. No dependencies or build step.

## Editing

Edit `index.html` and commit to `main`. GitHub Pages serves the repository root; changes publish automatically.

For a local preview, run `python3 -m http.server 8000` in a checkout and open http://localhost:8000/.

## Adding demonstrations

Place self-contained demos in a subdirectory, such as `demos/planet/index.html`, and link to them from the homepage. Use relative asset paths. Only commit material intended for public access.
